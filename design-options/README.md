# Design Lab

This folder is an isolated visual exploration shelf. Nothing in this folder is referenced by the production homepage or route templates.

## What is here

- `assets/wallpapers/` — five cinematic background directions with copy-safe negative space.
- `assets/busts/` — four fictional, full-head 3D character directions. They are intentionally archetypal and are not actor likenesses.
- `assets/emblems/` — four raised-metal medallions. They use one material language so the visible black ring problem can be avoided when we select a final crop and treatment.
- `index.html` — a responsive comparison gallery with text-field, label, and emoji moodboards.

## Visual findings from the current live site

1. The shared header and nav are now coherent; route identity should come from imagery and temperature rather than unrelated card skins.
2. The house rail is strong, but each emblem needs one consistent medallion crop and a single hover treatment. Mixing crop sizes is what makes the black boundary read as a second circle.
3. Large copy needs calmer negative space than the current hero provides on some routes. The wallpaper directions here reserve space for title, eyebrow, and one action.
4. Cards should become image-led panels with a restrained rule system. The gallery's four UI treatments show options without committing the live app to a new component system.
5. Emoji are useful for empty states and teaching moments, but the production navigation should retain accessible SVG/icon assets and text labels.
